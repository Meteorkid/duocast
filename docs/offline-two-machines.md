# 极端条件：两台电脑、无网线、无路由器、无第三方，怎么传文件

## 结论：只有一条路——**Mac 当热点，Windows 连上来**

```
Mac（开无外网热点） ⇄ Wi-Fi ⇄ Windows（连上，显示"无 Internet"，正常）
                              ↓
                    beam 走这条局域网，自动发现 + 加密 + 校验
```

方向不能反过来：**Windows 在完全没有外网时打不开移动热点**（微软文档与厂商支持页都写明「设备必须先连接可上网的 WLAN / 以太网 / 蜂窝」）。Mac 的「互联网共享」则允许把「来源」设成一个没联网的接口，仍然广播 Wi-Fi。

---

## 一、Mac 端：开一个没有外网的热点

**系统设置 → 通用 → 共享 → 互联网共享**

1. 「共享以下来源的连接」：选 **Thunderbolt Bridge**（或任意一个非 Wi-Fi 的接口）。**它不需要真的插着东西**——只要不是「无」，就能启动。
2. 「用以下端口共享给电脑」：勾 **Wi-Fi**。
3. 点右侧「Wi-Fi 选项…」：
   - 网络名称：例如 `beam-direct`
   - 安全性：**WPA2 个人级**（WPA3 在部分 Windows 网卡上兼容性差）
   - 密码：至少 8 位
   - 信道：能选就选 **5GHz**（默认常是 2.4GHz，速度差一倍以上）
4. 回到上一页，打开「互联网共享」开关 → 弹窗点「启动」。

看到菜单栏 Wi-Fi 图标变成**带向上箭头的基站图标**，就成功了。

> 如果下拉里选不到任何来源（新版 macOS 偶见），需要先用脚本给 `lo0` 加一个带静态 IP 的网络服务，让系统认为「有活动连接」，再回来选它。这一步要 sudo，属于系统配置改动，做之前先确认能回滚。

## 二、Windows 端：连上它

1. 点右下角网络图标 → 找到 `beam-direct` → 输入密码。
2. Windows 会提示「**无 Internet 访问**」——正常，忽略。只要是「已连接」，链路就通了。

## 三、传文件

```powershell
# Windows
beam.exe recv --listen :9001 --out D:\下载
```

```bash
# Mac
beam peers                              # 应能看到 Windows 的设备名
beam send 视频.mp4 --peer DESKTOP-XXXX
```

两边在同一子网（Mac 会通过 DHCP 给 Windows 分配 `192.168.2.x`），UDP 广播与 mDNS 都能工作，不需要记 IP。

网页模式同理：

```bash
beam ui --tcp-listen :9001 --out ~/下载
```

## 四、能到多快

取决于 Mac 的 Wi-Fi 芯片和频段：

| 频段 | 实测常见吞吐 |
| --- | --- |
| 5GHz（802.11ac/ax） | 30–70 MB/s |
| 2.4GHz | 5–12 MB/s |

这是 Wi-Fi 直连的天花板，已经接近隔空投送（AirDrop 走 AWDL，同样跑在 5GHz 上）。**比蓝牙快两个数量级，比网线慢一半左右。**

---

## 五、三个必须知道的坑

1. **Mac 的 Wi-Fi 会变成基站模式，自己就上不了网了。** 只有一块无线网卡，做 AP 和做客户端不能同时。传完记得关掉共享。
2. **Windows 那边「无 Internet」的提示不会消失**，这不是故障。有些应用会因为「网络未连接」而拒绝联网，但 beam 直接用 IP，不受影响。
3. **信道与频段**：默认 2.4GHz 时速度会让人失望。Mac 的互联网共享里如果选不到 5GHz，就把两端靠近些，或接受 2.4GHz 的速度。

## 六、为什么其他路都不通（已逐条排除）

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| Windows 开热点 | ❌ | 无外网时开关打不开（系统限制） |
| 蓝牙传文件 | ❌ | macOS 26 已移除「蓝牙文件交换」，蓝牙栈也不再广播 OBEX OPP / PAN |
| Wi-Fi Direct | ❌ | Windows 有、macOS 没有 |
| AWDL（隔空投送底层） | ❌ | macOS 有、Windows 没有；要移植到 Windows 需驱动级改造（见 `awdl-on-windows-plan.md`） |
| 雷雳线直连 | ⚠️ | Thunderbolt Bridge 在 macOS 存在，但 Mac↔Windows 的雷雳网络没有可靠支持，只能碰运气 |
| U 盘 | ✅ | 但题目排除了「其他帮助」 |

所以上面那一条不是「最优解」，是**唯一解**。
